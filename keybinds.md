# KWM Keybindings

Modifier: `Super` (Mod4)

## System

| Key | Action |
|-----|--------|
| `Super+Shift+r` | Reload config |
| `Super+Shift+q` | Exit session (exiland) |
| `Super+Shift+w` | Lock screen (waylock) |
| `Super+Shift+e` | Hibernate |
| `Super+Shift+c` | Close window |
| `Super+b` | Toggle bar |

## Applications

| Key | Action |
|-----|--------|
| `Super+Return` | Terminal (footclient) |
| `Super+p` | App launcher (wmenu-run-color) |
| `Super+q` | Browser (qutebrowser) |
| `Super+r` | File manager (lf) |
| `Super+v` | Floating terminal (dvtm) |

## Layout

| Key | Action |
|-----|--------|
| `Super+f` | Float layout |
| `Super+t` | Tile layout (master left) |
| `Super+Shift+t` | Tile layout (master right) |
| `Super+u` | Tile layout (master bottom) |
| `Super+Shift+u` | Tile layout (master top) |
| `Super+g` | Grid layout |
| `Super+o` | Deck layout |
| `Super+m` | Monocle layout |
| `Super+s` | Scroller layout |
| `Super+Shift+Tab` | Previous layout |
| `Super+Shift+g` | Toggle grid direction |

## Window Focus

| Key | Action |
|-----|--------|
| `Super+j` | Focus next |
| `Super+k` | Focus previous |
| `Super+Ctrl+j` | Focus next (skip floating) |
| `Super+Ctrl+k` | Focus previous (skip floating) |
| `Super+Ctrl+h` | Focus master |
| `Super+Ctrl+l` | Focus master |

## Window Swap

| Key | Action |
|-----|--------|
| `Super+Shift+j` | Swap forward |
| `Super+Shift+k` | Swap backward |

## Window State

| Key | Action |
|-----|--------|
| `Super+space` | Toggle floating |
| `Super+Shift+f` | Toggle fullscreen / maximize |
| `Super+e` | Toggle monocle fullscreen |
| `Super+Shift+s` | Toggle sticky |
| `Super+Shift+o` | Toggle swallow |
| `Super+z` | Zoom (swap with master) |
| `Super+Ctrl+o` | Toggle auto swallow |

## Master Area

| Key | Action |
|-----|--------|
| `Super+h` | Shrink master (-5%) |
| `Super+l` | Grow master (+5%) |
| `Super+i` | Increase master count |
| `Super+d` | Decrease master count |
| `Super+Alt+h` | Master left |
| `Super+Alt+l` | Master right |
| `Super+Alt+j` | Master bottom |
| `Super+Alt+k` | Master top |

## Gap

| Key | Action |
|-----|--------|
| `Super+Ctrl+[` | Increase gap |
| `Super+Ctrl+]` | Decrease gap |

## Output (Monitor)

| Key | Action |
|-----|--------|
| `Super+.` | Focus next output |
| `Super+,` | Focus previous output |
| `Super+Shift+.` | Send window to next output |
| `Super+Shift+,` | Send window to previous output |

## Tags (Workspaces)

| Key | Action |
|-----|--------|
| `Super+1-9` | Switch to tag 1-9 |
| `Super+0` | Switch to all tags |
| `Super+Tab` | Previous tag |
| `Super+\` | Previous tag |
| `Super+Shift+1-9` | Move window to tag 1-9 |
| `Super+Shift+0` | Move window to all tags |
| `Ctrl+1-9` | Toggle tag 1-9 |
| `Super+Ctrl+1-9` | Toggle window tag 1-9 |
| `Super+'` | Next occupied tag |
| `Super+;` | Previous occupied tag |
| `Super+Ctrl+'` | Next unoccupied tag |
| `Super+Ctrl+;` | Previous unoccupied tag |

## Audio

| Key | Action |
|-----|--------|
| `Super+-` | Volume down 10% |
| `Super+=` | Volume up 10% |
| `Super+Shift+-` | Volume down 5% |
| `Super+Shift+=` | Volume up 5% |
| `Super+BackSpace` | Mute sink |
| `Super+Ctrl+-` | Mic volume down 10% |
| `Super+Ctrl+=` | Mic volume up 10% |
| `Super+Ctrl+Shift+-` | Mic volume down 5% |
| `Super+Ctrl+Shift+=` | Mic volume up 5% |
| `Super+Ctrl+BackSpace` | Mute source |

## Floating Mode (`Super+Ctrl+f` to enter)

| Key | Action |
|-----|--------|
| `h/j/k/l` | Move window |
| `y/u/i/o` | Resize window |
| `Super+Shift+h/j/k/l` | Snap to edge |
| `Escape` / `Space` | Exit floating mode |

## WMenu Mode (`Super+w` to enter)

| Key | Action |
|-----|--------|
| `w` | Wiki |
| `h` | Heart |
| `b` | Books |
| `u` | Bluetooth |
| `s` | Speaker |
| `e` | Emoji |
| `j` | Jdoc |
| `Escape` / `Space` / `Super+w` | Exit mode |

## Dunst Mode (`Super+x` to enter)

| Key | Action |
|-----|--------|
| `l` | List updates |
| `w` | Weather (wttr) |
| `c` | Calendar |
| `m` | List music |
| `i` | Clear clipboard |
| `Escape` / `Space` / `Super+x` | Exit mode |

## WLRCTL Mode (`Super+/` to enter)

Keyboard mouse control:

| Key | Action |
|-----|--------|
| `h/j/k/l` | Move pointer (fast) |
| `Shift+h/j/k/l` | Move pointer (slow) |
| `Ctrl+h/j/k/l` | Arrow keys |
| `,` | Left click |
| `.` | Right click |
| `Shift+,` | Left click |
| `Shift+.` | Right click |
| `n` | Scroll down |
| `p` | Scroll up |
| `Escape` / `Space` / `Super+/` | Exit mode |

## Passthrough Mode (`Super+Shift+Escape` to enter)

All kwm shortcuts disabled. `Super+Shift+Escape` to exit.

## Pointer

| Action | Binding |
|--------|---------|
| Move window | `Super+Left drag` |
| Resize window | `Super+Right drag` |
